# 🧾 Sistema Punto de Venta (POS) + Estadísticas + Cotizaciones

Sistema completo de **Punto de Venta** desarrollado para la gestión de ventas en tiendas, negocios y comercios, incluyendo **control de productos**, **usuarios**, **cortes de caja**, **cotizaciones**, y un módulo de **estadísticas/reportes** para análisis de ventas.

---

## 🚀 Características principales

### 🛒 Punto de Venta
- Venta rápida con búsqueda de productos por nombre/código
- Control de stock en tiempo real
- Aplicación de descuentos
- Manejo de múltiples métodos de pago (efectivo / tarjeta / mixto)
- Generación de ticket de venta
- Historial de ventas por usuario y por fecha

### 📦 Gestión de Productos
- Alta / edición / eliminación de productos
- Categorías y marcas
- Código de barras
- Control de inventario (entradas/salidas)
- Alertas por stock mínimo

### 👤 Gestión de Usuarios y Roles
- Login seguro
- Roles disponibles:
  - **Administrador**
  - **Cajero**
  - **Supervisor**
- Permisos por módulo

### 💰 Cortes de Caja
- Apertura y cierre de caja
- Registro de ingresos y egresos
- Cálculo automático de efectivo esperado
- Reporte de diferencias (sobrante/faltante)
- Historial de cortes por usuario

### 🧾 Cotizaciones
- Creación de cotizaciones con productos del inventario
- Conversión de cotización a venta
- Impresión / exportación (PDF)
- Seguimiento de cotizaciones (pendiente / aceptada / cancelada)

### 📊 Estadísticas y Reportes
- Dashboard general con métricas:
  - Ventas del día / semana / mes
  - Productos más vendidos
  - Ventas por usuario/cajero
  - Ventas por categoría
- Exportación de reportes PDF y Excel
